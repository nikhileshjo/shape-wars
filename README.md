# Shape wars

This is a game where you make points by shooting your enemy shapes. You the hero player shoots down the evil shapes that are after you to take your life. Will you survive?

# Setup
The setup requires you to have [cmake](https://cmake.org/) installed. The below is the setup for your project:
```
git clone https://github.com/nikhileshjo/shape-wars.git
cd shape-wars
```

Now, test if everything works:
```
mkdir build
cd build
cmake ../
cmake --build .
```
if everything goes smoothly, your build will complete successfully. Once that's done, run the executable from root folder: `./build/src/start_game`
